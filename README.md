# Spectroscopical property predictor (specj_ai)

This repository includes a main app.py where the user can easily make inference predictions for different spectroscopial properties (lifetime, quantum yield or radiative constant).

## Requerimenss📋

* **Python 3.8** or greater.

---

## Configuration

**1. Clone respository**

```sh
git clone https://github.com/JuanCSG10/specj_ai.git
cd specj_ai
```

**2. Create virtual env and activate**

```sh
python -m venv venv
source venv/bin/activate
```

**3. Install requeriments**

```sh
pip install -r requirements.txt
```

**4. Execute main app**

```sh
python3 app.py
```
